# Cost Estimate

## Free-tier MVP

- Hosting: Vercel free tier or similar
- Database: browser local storage
- Market data: no-key delayed provider
- AI: deterministic educational scoring
- Estimated monthly cost: $0

## Low-cost personal cloud version

- Hosting: Vercel/Netlify paid or free tier depending usage
- Database: Supabase free or low-cost tier
- Market data: FMP/Twelve Data/Finnhub low-tier API
- AI: OpenAI or other model API with strict usage limits
- Estimated monthly cost: roughly $0–$30 depending provider choices and usage

## Production-ready version

- Hosting: paid serverless hosting
- Database: paid Supabase/Postgres
- Redis/cache: managed cache
- Market data: licensed paid provider
- AI: production model usage
- Monitoring: paid observability
- Estimated monthly cost: highly variable, commonly $50+ for a serious always-on setup
